\chapter{CONCLUSION}

This report has presented a complete statically-typed interpreted language with
four primitive types --- Integer, Float, Boolean, and String --- together with
assignment, control flow, user-defined functions, and a built-in
\texttt{print()} function. The implementation integrates lexical analysis,
parsing, static semantic analysis, and interpretation into a coherent
four-stage pipeline. Types are inferred without explicit declarations, and
ill-typed programs are rejected before execution.

A key design decision is the use of distinct operator tokens for integer and
floating-point arithmetic, following the Caml~Light convention. This eliminates
implicit numeric promotion and ensures that each operator has exactly one type
signature, yielding deterministic type inference. The system also exposes both
a grammar-oriented parse-tree view and an executable AST, while the automated
test suite of 77 tests confirms correct behaviour across lexical analysis,
symbol-table handling, parsing, type checking, and end-to-end execution.

The result is a clear and modular language-processing pipeline with strong
static guarantees and inspectable intermediate forms. Future work could extend
the language with recursive functions, richer data structures, and code
generation.
