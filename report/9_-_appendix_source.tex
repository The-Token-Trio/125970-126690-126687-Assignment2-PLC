\chapter*{APPENDIX A: SOURCE CODE}
\addcontentsline{toc}{chapter}{APPENDIX A: SOURCE CODE}

This appendix includes representative source files that highlight the core
implementation of the language processor. The selected listings focus on the
principal implementation stages: lexical analysis, parsing, static semantic
analysis, interpretation, and program entry. The complete codebase is
available in the linked repository.

Source code repository:

\begin{center}
\textbf{https://github.com/The-Token-Trio/125970-126690-126687-Assignment2-PLC}
\end{center}

Video walkthrough:

\begin{center}
\textbf{https://youtu.be/sR2JRm6eYzM}
\end{center}

Run commands:

\begin{lstlisting}
# macOS / Linux
python3 main.py
python3 ui.py
python3 -m unittest discover -s tests -v

# Windows
python main.py
python ui.py
python -m unittest discover -s tests -v
\end{lstlisting}

No external Python dependencies are required.
